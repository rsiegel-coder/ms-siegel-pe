# Ms. Siegel's Physical Education Website

Publish-ready static website for GitHub Pages.

## Upload to GitHub
Upload **index.html**, **.nojekyll**, and the **assets** folder to the root of the repository. Do not upload only the ZIP.

Then open repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.

The site contains no student-specific data. Keep it that way when editing the public site.
